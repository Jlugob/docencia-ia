# Referentes curriculares de Colombia (MEN y normativa)

Módulo por defecto del kit. Para otro país o para materias que no están aquí, agregar un archivo
`<materia>.md` con el mismo esquema (qué referente oficial tiene, sus componentes y competencias, y
cómo se rotulan las columnas de la malla) y extractos literales en `fuentes/`.

Base documental para construir mallas, parcelaciones, programas de periodo y talleres. Revisión
del 15/11/2026; antes de cerrar documentos oficiales, volver a comprobar lo marcado con ⚠.

| Archivo | Contenido |
